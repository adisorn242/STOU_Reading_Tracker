# 📚 STOU Reading Tracker — บันทึกการอ่านหนังสือ STOU

เว็บแอปสำหรับติดตามความคืบหน้าการอ่านหนังสือเรียนของมหาวิทยาลัยสุโขทัยธรรมาธิราช (มสธ.) ที่แต่ละวิชามีเนื้อหา 15 บท เป็นไฟล์ HTML เดี่ยว เปิดใช้งานได้ทันทีจากเบราว์เซอร์โดยไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องเชื่อมต่ออินเทอร์เน็ต (ยกเว้นฟอนต์ที่โหลดจาก Google Fonts)

## ✨ ฟีเจอร์

- ตั้งค่าวิชา 1 ไฟล์ต่อ 1 วิชา ด้วยรหัสวิชาและชื่อวิชา
- บันทึกการอ่านแต่ละครั้ง: วันที่, ตอนที่, หน้าที่อ่านถึง — ระบุได้หลายตอนในการบันทึกครั้งเดียว (ต้องอยู่ในบทเดียวกัน)
- ติ๊กช่อง **"อ่านจบบทนี้แล้ว"** แยกอิสระในแต่ละบท พร้อมระบุ/แก้ไขวันที่อ่านจบได้เอง
- คำนวณระยะเวลาที่ใช้อ่านแต่ละบทอัตโนมัติ (วันที่เริ่มบันทึกครั้งแรกของบท → วันที่ติ๊กจบ)
- บันทึกคะแนนสอบก่อนเรียน (Pre-test) และหลังเรียน (Post-test) รายบท
- สรุปภาพรวม: จำนวนบทที่อ่านจบ, ความคืบหน้า %, จำนวนวันที่ใช้อ่านไปแล้ว
- **นับวันแบบไม่ซ้ำ**: หากวันที่เริ่มอ่านบทถัดไปตรงกับวันที่อ่านจบบทก่อนหน้าพอดี ระบบจะนับวันนั้นเพียงครั้งเดียว ไม่นับซ้ำ
- แก้ไข/ลบบันทึกย้อนหลังได้
- นำเข้า (Import) / ส่งออก (Export) ข้อมูลเป็นไฟล์ **JSON** เพื่อสำรอง/ย้ายข้อมูล
- ส่งออกข้อมูลเป็นไฟล์ **CSV** เพื่อเปิดดูใน Excel / Google Sheets
- บันทึกข้อมูลอัตโนมัติลง **Local Storage** ของเบราว์เซอร์ (ข้อมูลอยู่เฉพาะในเครื่อง/เบราว์เซอร์ที่ใช้งาน)
- ดีไซน์สีสันสดใส ใช้งานง่าย รองรับหน้าจอมือถือ

## 🚀 วิธีใช้งาน

1. ดาวน์โหลดไฟล์ `stou-reading-tracker.html`
2. ดับเบิลคลิกเปิดไฟล์ด้วยเบราว์เซอร์ (Chrome, Edge, Firefox ฯลฯ)
3. กรอกรหัสวิชาและชื่อวิชาที่ต้องการติดตาม แล้วกด "เริ่มบันทึก"
4. เปิดการ์ดบทที่ต้องการ กด "เพิ่มบันทึกการอ่าน" เพื่อบันทึกตอน/หน้าที่อ่าน และติ๊ก "อ่านจบบทนี้แล้ว" เมื่ออ่านจบ
5. กด "ส่งออก JSON" เป็นระยะเพื่อสำรองข้อมูล หรือ "ส่งออก CSV" เพื่อนำไปวิเคราะห์ต่อ

> ⚠️ ข้อมูลถูกเก็บไว้ใน Local Storage ของเบราว์เซอร์นั้น ๆ เท่านั้น หากล้างข้อมูลเบราว์เซอร์ (clear browsing data) หรือเปลี่ยนเครื่อง/เบราว์เซอร์ ข้อมูลจะหายไป จึงแนะนำให้ส่งออก JSON เก็บไว้เสมอ และสามารถนำเข้า (Import) กลับมาใช้งานใหม่ได้ทุกเมื่อ

## 🖥️ เทคโนโลยีที่ใช้

- HTML + CSS + Vanilla JavaScript (ไม่มี framework, ไม่ต้อง build)
- Local Storage API สำหรับเก็บข้อมูล
- ฟอนต์ [Kanit](https://fonts.google.com/specimen/Kanit) จาก Google Fonts
