# 📚 STOU Reading Tracker — บันทึกการอ่านหนังสือ STOU

เว็บแอปสำหรับติดตามความคืบหน้าการอ่านหนังสือเรียนของมหาวิทยาลัยสุโขทัยธรรมาธิราช (มสธ.) ที่แต่ละวิชามีเนื้อหา 15 บท เป็นไฟล์ HTML เดี่ยว เปิดใช้งานได้ทันทีจากเบราว์เซอร์โดยไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องเชื่อมต่ออินเทอร์เน็ต (ยกเว้นฟอนต์ที่โหลดจาก Google Fonts)

## ✨ ฟีเจอร์

- 📚 **รองรับหลายวิชาในไฟล์เดียว** อย่างน้อย 1 วิชา คลิกป้ายวิชาด้านบนเพื่อสลับ หรือกด "➕ เพิ่มวิชาใหม่" เพื่อเพิ่มอีกวิชา แต่ละป้ายบอกสถานะล่าสุดของวิชานั้นให้เห็นทันที (ลบวิชาได้ แต่ต้องเหลืออย่างน้อย 1 วิชาเสมอ)
- 🗓️ ระบุ **ปีการศึกษา (พ.ศ.)** และ **ภาคการศึกษา (1/2/3)** ต่อวิชาได้ แสดงผลไว้ที่หัวข้อวิชา
- 🗂️ **แท็บกรองตามเทอม** ปรากฏขึ้นอัตโนมัติเมื่อมีวิชาจากหลายเทอม (เช่น 2 เทอมคาบเกี่ยวกัน) คลิกเพื่อกรองรายชื่อวิชาที่แสดง ไม่ต้องไล่หาท่ามกลางวิชาทั้งหมด
- 📍 **แบนเนอร์สถานะปัจจุบัน** แสดงชัดเจนว่าตอนนี้อ่านถึงบทที่ / ตอนที่ / หน้าไหนแล้ว จากการบันทึกล่าสุด
- 🔄 **รองรับหลายรอบการอ่าน** (อ่านทบทวนซ้ำ 2-3 รอบได้) โดยต้องอ่านให้ครบทั้ง 15 บทในรอบปัจจุบันก่อน จึงจะเริ่มรอบใหม่ได้ ข้อมูลแต่ละรอบแยกเก็บต่างหาก สลับดูย้อนหลังได้
- 📊 **กราฟคะแนนสอบก่อน-หลังเรียน** เปรียบเทียบทั้ง 15 บทของรอบปัจจุบันแบบกราฟแท่ง (% คะแนน) วาดด้วย SVG ล้วน ไม่ต้องพึ่งไลบรารีภายนอก
- การ์ดแต่ละบทแสดงเป็น **box กระชับ** เรียงเป็นตาราง คลิกเพื่อคลี่ดู/แก้ไขรายละเอียดแบบเต็ม ไม่ต้องเลื่อนหน้าจอเยอะ
- บันทึกการอ่านแต่ละครั้ง: วันที่, ตอนที่ (รองรับรูปแบบ บท.ตอน เช่น `3.1` และพิมพ์หลายตอนคั่นด้วยจุลภาคในช่องเดียว เช่น `3.1,3.2,3.3` ได้ทันที), หน้าที่อ่านถึง — ระบุได้หลายตอนในการบันทึกครั้งเดียว (ต้องอยู่ในบทเดียวกัน)
- ติ๊กช่อง **"อ่านจบบทนี้แล้ว"** แยกอิสระในแต่ละบท พร้อมระบุ/แก้ไขวันที่อ่านจบได้เอง
- คำนวณระยะเวลาที่ใช้อ่านแต่ละบทอัตโนมัติ (วันที่เริ่มบันทึกครั้งแรกของบท → วันที่ติ๊กจบ)
- บันทึกคะแนนสอบก่อนเรียน (Pre-test) และหลังเรียน (Post-test) รายบท
- สรุปภาพรวม: จำนวนบทที่อ่านจบ, ความคืบหน้า %, จำนวนวันที่ใช้อ่านไปแล้ว (ต่อรอบ)
- **นับวันแบบไม่ซ้ำ**: หากวันที่เริ่มอ่านบทถัดไปตรงกับวันที่อ่านจบบทก่อนหน้าพอดี ระบบจะนับวันนั้นเพียงครั้งเดียว ไม่นับซ้ำ
- แก้ไข/ลบบันทึกย้อนหลังได้
- นำเข้า (Import) / ส่งออก (Export) ข้อมูลเป็นไฟล์ **JSON** เพื่อสำรอง/ย้ายข้อมูล (รวมทุกวิชาและทุกรอบ)
- ส่งออกข้อมูลเป็นไฟล์ **CSV** เพื่อเปิดดูใน Excel / Google Sheets (รวมทุกวิชาและทุกรอบ)
- 🗄️ **ส่งออก/นำเข้าเป็นไฟล์ SQLite (.sqlite) แท้ ๆ** ได้ด้วย (ผ่าน sql.js) เป็นฐานข้อมูลเชิงสัมพันธ์จริง เปิดต่อด้วยโปรแกรมอื่นได้ เช่น DB Browser for SQLite — ไม่ได้แทนที่ JSON แต่เป็นทางเลือกเพิ่มเติมสำหรับพกพา/วิเคราะห์ข้อมูลนอกเบราว์เซอร์ (ต้องเชื่อมต่ออินเทอร์เน็ตครั้งแรกที่ใช้ฟีเจอร์นี้เพื่อโหลดตัวประมวลผล)
- บันทึกข้อมูลอัตโนมัติลง **Local Storage** ของเบราว์เซอร์ (ข้อมูลอยู่เฉพาะในเครื่อง/เบราว์เซอร์ที่ใช้งาน) พร้อมแบนเนอร์เตือนให้สำรองข้อมูลอย่างชัดเจน
- ดีไซน์สีสันสดใส ใช้งานง่าย รองรับหน้าจอมือถือ

## 🚀 วิธีใช้งาน

1. ดาวน์โหลดไฟล์ `STOU_reading_tracker.html`
2. ดับเบิลคลิกเปิดไฟล์ด้วยเบราว์เซอร์ (Chrome, Edge, Firefox ฯลฯ)
3. กรอกรหัสวิชา ชื่อวิชา ปีการศึกษา และภาคการศึกษาที่ต้องการติดตาม แล้วกด "เริ่มบันทึก"
4. คลิก box บทที่ต้องการเพื่อคลี่ดูรายละเอียด กด "เพิ่มบันทึกการอ่าน" เพื่อบันทึกตอน/หน้าที่อ่าน และติ๊ก "อ่านจบบทนี้แล้ว" เมื่ออ่านจบ
5. เมื่ออ่านครบทั้ง 15 บทในรอบนี้แล้ว สามารถกด "เริ่มรอบใหม่" ด้านบนเพื่ออ่านทบทวนรอบถัดไปได้
6. ต้องการติดตามอีกวิชา? กด "➕ เพิ่มวิชาใหม่" ที่ป้ายด้านบนสุด แล้วสลับไปมาระหว่างวิชาได้ตลอดเวลา
7. กด "ส่งออก JSON" เป็นระยะเพื่อสำรองข้อมูล (รวมทุกวิชา) หรือ "ส่งออก CSV" เพื่อนำไปวิเคราะห์ต่อ

> ⚠️ ข้อมูลถูกเก็บไว้ใน Local Storage ของเบราว์เซอร์นั้น ๆ เท่านั้น หากล้างข้อมูลเบราว์เซอร์ (clear browsing data) หรือเปลี่ยนเครื่อง/เบราว์เซอร์ ข้อมูลจะหายไป จึงแนะนำให้ส่งออก JSON เก็บไว้เสมอ (ในแอปเองก็มีแบนเนอร์เตือนสีแดงเรื่องนี้ไว้แล้ว) และสามารถนำเข้า (Import) กลับมาใช้งานใหม่ได้ทุกเมื่อ

## 🖥️ เทคโนโลยีที่ใช้

- HTML + CSS + Vanilla JavaScript (ไม่มี framework, ไม่ต้อง build)
- Local Storage API สำหรับเก็บข้อมูลหลัก (ใช้งานได้แบบออฟไลน์เต็มรูปแบบ)
- [sql.js](https://sql.js.org/) (SQLite คอมไพล์เป็น WebAssembly) โหลดแบบ lazy จาก CDN เฉพาะตอนกดส่งออก/นำเข้า SQLite เท่านั้น — ฟีเจอร์อื่นทั้งหมดไม่ต้องพึ่งอินเทอร์เน็ต
- กราฟคะแนนวาดด้วย SVG ล้วน ไม่พึ่งไลบรารีกราฟภายนอก
- ฟอนต์ [Kanit](https://fonts.google.com/specimen/Kanit) จาก Google Fonts

### โครงสร้างตารางในไฟล์ SQLite ที่ส่งออก

```
subjects(id, subject_code, subject_name, academic_year, semester, current_round)
rounds(id, subject_id, round_number)
chapters(id, round_id, chapter_number, pre_test, pre_test_max, post_test, post_test_max, completed, completed_date)
logs(id, chapter_id, log_date)
log_sections(id, log_id, section, page)
```
